# Windows 兼容性与内存验证记录

验证日期：2026-09-30。环境为 Windows x64（10.0.26200）、Python 3.12.14、桌面 Excel 16.0、pywin32 312，使用项目独立 `.venv`。以下为本机实测，不代表所有 Office 语言版本或 Linux 环境均已重测。

## 兼容性检查与修复

- 原 Windows 导出在设置 `NumberFormat = "General"` 时直接失败；独立 Excel 实验确认当前语言环境拒绝该字符串，数字格式可正常设置。改为保留模板原有汇率格式，并将金额格式应用到完整合并区域。
- 通过 COM 写入文字时使用 Excel 文本前缀，避免 `=1+1` 被执行为公式或 `00123` 丢失前导零。OOXML 写入路径继续直接存储原始文字。
- Windows 每个服务进程同时最多执行一项 Excel 导出，排队最长 120 秒；异常时释放名额。独立实例填值期间关闭自动重算，填完统一重算，保存前恢复自动模式。使用正常打开模式，关闭事件和宏；只关闭本次创建的实例。
- 清理导出异常分支的 COM 引用，缺少 Excel/pywin32 时给出实际可执行的提示，移除对不存在的 `run.bat` 的引用。
- Windows 锁定依赖复用主依赖版本并加入 pywin32，补齐历史文件遗漏的 lxml；开发依赖在 Windows 下也安装 pywin32。Docker 的运行版本未改变。
- 将“缺少 LibreOffice”的测试明确指向 Linux 后端；POSIX 进程组/可执行脚本测试在 Windows 上正确跳过，补充了真实 Excel 测试。

## 内存与速度

每项使用新 Python 进程、同一解释器和同一输入。目录优化前后完整数据快照一致：229 个职业、67 个技能槽、104 件武器、430 条物品记录及汇率、字段映射等均一致。校验对比使用同一份已经 Excel 重算的有效合成人物文件。

| 阶段 | Python 分配峰值：优化前 → 后 | 降幅 | 跟踪模式耗时：优化前 → 后 |
| --- | --- | --- | --- |
| 模板目录加载 | 42.673 → 7.386 MiB | 82.7% | 6.356 → 0.625 秒 |
| XLSX 结果校验 | 83.952 → 1.551 MiB | 98.2% | 12.785 → 1.632 秒 |

对应的进程峰值工作集分别为 138.828 → 48.984 MiB、245.258 → 37.891 MiB。测量启用了 `tracemalloc`，工作集包含内存跟踪开销，不能直接当作日常运行 RSS；这些数值也不包含独立 Excel 进程。单次本机测量不是多机统计基准。

目录使用 openpyxl 的只读流式模式，并对职业矩阵等区域一次读取后索引，避免随机访问导致反复解析。只读模式需要显式关闭工作簿，见 [openpyxl 只读模式说明](https://openpyxl.readthedocs.io/en/3.0/optimized.html)。校验则直接流式读取 ZIP 中的 XML，检查公式和缓存值，不再同时持有两本完整工作簿。

Windows 重算仅改变独立实例的设置，保存前恢复自动计算；Excel 的计算模式属于应用级设置，见 [Microsoft Excel 计算模式说明](https://learn.microsoft.com/en-us/troubleshoot/microsoft-365-apps/excel/current-mode-of-calculation)。未修改用户已有实例的计算选项。

基准入口为 `scripts/benchmark_memory.py`。本次原始 JSON、目录快照、旧校验器对照和合成人物结果保存在 Git 忽略的 `test-output/windows-memory/`。

## 实际验证结果

- 优化前完整 Windows 回归：163 通过、13 跳过、2 失败。失败分别是测试误走 Windows 后端，以及在 Windows 执行 POSIX 超时脚本；独立的真实 Windows 导出另复现了上述数字格式错误。
- 优化后启用 `COC7_TEST_EXCEL=1` 并设置 Node 路径：184 通过、14 跳过，另有 4 个子用例通过。最后增加“版本说明单元格含空结果公式仍须拒绝”的回归后，相关流式校验与目录测试 8 项全部通过。
- 跳过项为本机未安装 LibreOffice 的重算测试及 Windows 不支持的 POSIX 进程组超时测试。没有将这些跳过计作通过；本次未在 Linux/LibreOffice 中实际重算。
- 真实 Excel 验证包括普通/自定义职业、头像、1920 年美元和 2026 年英镑、文字保真、导出再导入、重新打开后的自动计算、币种下拉与两项并发人物隔离。模板哈希保持不变。
- 使用独立本机监听端口跑通 HTTP 冒烟：首页、健康接口、107 个年份、1,061 条有效报价、60 条缺失报价、两页 PDF、14 页 XLSX、英镑现金 91.72，以及成长点/经历包点联动均通过。验证后临时服务已停止。
- `pip check` 无依赖冲突；新 Windows 锁定文件通过离线 dry-run；`git diff --check` 通过。

测试库当前有 Starlette/httpx 与 AnyIO API 的弃用提示，不影响本次结果。Windows Excel COM 的执行过程尚无强制进程超时；120 秒限制仅用于排队。安装了 Excel 的交互式 Windows 桌面已验证，Windows 服务账户及无人登录环境未测试。
