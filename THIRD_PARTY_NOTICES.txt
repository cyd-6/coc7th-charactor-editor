COC7 Investigator Builder - Docker edition

This edition installs its Linux components when the image is built.
Verified Python package versions are listed in requirements.lock.txt.
Python package metadata and license files are installed under the image's
/usr/local/lib/python3.12/site-packages/*.dist-info directories.
Debian package copyright and license files are under /usr/share/doc/.
